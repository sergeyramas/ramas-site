## Почему сейчас — окно возможности

GEO (Generative Engine Optimization) — оптимизация контента под ответы генеративных AI-поисковиков: Google AI Overview, Perplexity, ChatGPT Search и подобные. Ниша молодая, правила ещё формируются, устоявшихся игроков почти нет — конкуренция на порядок ниже, чем в обычном SEO.

Это окно, а не постоянное состояние рынка. Кто заходит в GEO сейчас, собирает цитируемость и трафик, которые через год-два придётся отвоёвывать в разы дороже — если вообще получится: цена входа растёт вместе с числом игроков, уже понявших правила.

## Что это

Собственная система автогенерации SEO/GEO-оптимизированных статей, написанная кодом — без n8n. Архитектура построена по мотивам открытой методики Дмитрия Попова (Кибер SEO & GEO): публичные материалы разобраны и переосмыслены в код с нуля, без покупки его спринта.

Почему код вместо n8n-воркфлоу: пайплайн — это HTTP-запросы и JSON между шагами. То, что в n8n делается Code Node на JS (валидация, сборка HTML), в коде — обычные функции с типами. Плюс git, тесты и переиспользование кусков между проектами — из коробки, а не через экспорт workflow.json.

## Архитектура — конвейер 7+1 воркфлоу

```
MASTER — оркестратор, по крону читает очередь статей
  │
  ├─ BRAIN      разведка SEO + семантика → JSON-blueprint статьи
  ├─ HOOK       H1, интро, key takeaways, meta, TOC
  ├─ BODY loop  генерация секций с humanizer-пайплайном
  ├─ ASSEMBLY   заключение, hard-CTA, FAQ+Schema, финальный HTML
  ├─ PUBLISHER  публикация через WordPress REST API
  ├─ INDEXER    отправка в Google и Яндекс Indexing API
  └─ IMAGE GEN  генерация картинок к статье, с ретраями
```

Семь воркфлоу плюс один оркестратор сверху — отсюда «7+1». Каждый шаг — самостоятельный модуль со своим входом и выходом: упало на INDEXER — не значит, что нужно перегенерировать статью заново, повторяется только последний шаг.

## 12 AI-агентов

Каждый узел конвейера — это не одна модель на всё, а несколько узкоспециализированных агентов, у каждого свой промпт под одну задачу:

|---|---|---|---|
| 1 | Chief Investigator | Perplexity | Research-досье по теме перед генерацией |
| 2 | Architect | Claude Sonnet | JSON-blueprint статьи |
| 3 | Research Manager | Claude + Perplexity | Факты и цифры для конкретных секций |
| 4 | Journalist | Claude Sonnet | H1, интро, summary |
| 5 | Writer | Claude Sonnet | Черновик секций |
| 6 | Editor | Claude Sonnet | Полировка под tone of voice |
| 7 | Structurer | Claude Sonnet | Таблицы, шаги, цитаты |
| 8 | ArtDirector | Claude Haiku | Промпты для картинок |
| 9 | Image Worker | image-router | Генерация картинок, с ретраями |

| 12 | Librarian | Claude Haiku | Внутренняя перелинковка с уже опубликованными статьями |

Узкий агент проще проверить и переиспользовать отдельно, чем один агент, который «пишет всё».

## Эталон качества страницы

Целевая страница — не голый текст, а 18 HTML-блоков со Schema.org-разметкой (Article, FAQPage). Плюс то, что типичная SEO-статья прошлых лет не делает:

- `llms.txt` и настройки robots под AI-краулеров
- OG- и Twitter-карточки для шеринга
- мониторинг GEO-позиций — не только «где статья в выдаче Google», но и цитирует ли её AI-поиск

## Маркетинг и применение

Движок задуман сразу под три контура:

1. **Для своих проектов** — контент-конвейер для собственных сайтов и хабов.
2. **Под клиентские сайты** — услуга «контент под ключ»: приносишь нишу и семантику, забираешь готовые статьи.
3. **Как SaaS-платформа** — тот же движок, обёрнутый в подписку, чтобы любой мог гнать GEO-контент без своей инфраструктуры.
