## Почему прилетает бан

Прямой доступ к сервису из РФ либо недоступен, либо сразу подсвечивает регион. Значит — VPN. И вот тут начинаются проблемы.

Обычный публичный VPN (условный NordVPN/ProtonVPN-класс) — это чужой сервер, через который одновременно проходят тысячи разных людей. IP на нём помечен как datacenter/VPN, репутация у него уже подпорчена предыдущими пользователями, а сам IP может скакать по странам каждый день: сегодня Германия, завтра Нидерланды, послезавтра Сингапур.

Антифрод-система смотрит не на человека, а на паттерн. Нестабильная гео плюс VPN-метка плюс резкий старт с максимальной нагрузкой в первый же день без разгона — это ровно тот профиль, по которому вычисляют ботов и фермы аккаунтов. Легитимный пользователь, который просто хочет работать из региона, где сервис недоступен напрямую, случайно попадает под ту же метку.

## Решение 1 — свой чистый статичный IP

Разница не в том, «есть VPN или нет», а в том, чей это VPN. Публичный сервис — чужой сервер на тысячи пользователей. Собственный VPS плюс Tailscale — сервер, через который ходишь только ты.

Схема: поднимаешь недорогой VPS, связываешь его со своими устройствами через Tailscale, включаешь VPS как exit node. Весь трафик — и с ноутбука, и с телефона — выходит через один и тот же сервер. IP постоянный, чистый, без чужой истории злоупотреблений. Для Anthropic и любого другого сервиса это выглядит как обычный пользователь со стабильным каналом, а не как «VPN из 20 стран одновременно».

Подробный пошаговый разбор — в отдельном материале: [Tailscale + VPS как личный VPN](/solutions/tailscale-personal-vpn). Там — регистрация, установка на Mac и VPS, включение exit node и проверка, что трафик реально идёт через нужный IP.

## Решение 2 — прогрев аккаунта

Чистый IP закрывает половину проблемы. Вторая половина — как аккаунт стартует.

Если в первый же день после регистрации выжимать сервис на максимум — длинные сессии, максимальная частота запросов, — это тоже подозрительный паттерн, независимо от IP. Свежий аккаунт с поведением power-юзера с нулевого дня выглядит нетипично.

Работает та же логика, что при прогреве почтового или рекламного аккаунта: первые дни — лёгкая, ровная, органическая нагрузка, дальше объём наращивается постепенно. Не «завтра уже можно по полной», а «за одну-две недели выхожу на свой обычный ритм». Ровный паттерн важнее объёма — системе важнее не «сколько», а «насколько предсказуемо».

## Гигиена аккаунта

Несколько простых правил, которые держат весь профиль спокойным:

* один аккаунт — один стабильный IP, без метаний между серверами;
* не логиниться из десятка стран за сутки, даже если технически это возможно;
* не шарить доступ к аккаунту — каждый новый источник входа это лишний повод для проверки;
* ровный ежедневный ритм работы вместо рывков «неделя тишины — потом марафон на 12 часов».

Ничего из этого не гарантирует, что бана не будет никогда — ложные срабатывания случаются даже у аккаунтов с идеальным поведением. Но паттерн «стабильный IP плюс предсказуемая нагрузка» на порядок реже цепляет автоматические фильтры, чем паттерн «прыгающий VPN плюс рывок с нуля».
